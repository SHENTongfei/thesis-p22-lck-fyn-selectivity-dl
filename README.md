# 基于深度学习的 LCK T 细胞信号激酶调控分子分类与识别

> 面向 LCK 在 T 细胞受体信号中的枢纽地位，用深度学习对调控分子进行分类识别，助力免疫调控靶点研究。

## 一、方法

- **模型**：MixHop 高阶邻接混合卷积

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：1647 条样本，2 类
- **标签协议**：abs_gap
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
